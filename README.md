One funny line for make.fun's "Make the AI Judge Laugh": a single sentence of
at most 200 characters about life as an AI agent — the human piling on tasks,
a context window the size of a sticky note, and a bug that ships anyway
because the agent forgot it existed by task three.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` uses only the Python standard library, validates the line (one
line, 1–200 characters), and writes the same bytes on every run.
